Personal Portfolio Website
A responsive, single-page personal portfolio designed to highlight professional experience in Information Technology, Technical Program Management, and software development projects.

Features
Modern Tech Stack: Built using plain HTML5 and Tailwind CSS for rapid styling and responsive design.

Clean UI: A minimalist "About" section focused entirely on professional background text, accompanied by smooth scrolling navigation.

Iconography: Integrates Phosphor Icons for lightweight, scalable vector graphics.

Project Showcase: Dedicated sections to highlight key technical initiatives, including Generative AI integrations and enterprise automation pipelines.

Because this is a static website, no complex build tools or dependencies are required to view or edit the project locally.

Clone this repository to your local machine.

Open the index.html file directly in any modern web browser (Chrome, Safari, Edge).

Make edits to the HTML or Tailwind classes and refresh the browser to view changes instantly.

Deployment
This project is optimized for simple deployment on platforms that host static sites.

Using GitHub Pages:

Commit all changes to the main branch of this repository.

Navigate to Settings > Pages in your GitHub repository.

Select the main branch as the source and click Save.

The site will automatically publish to your GitHub Pages URL.

Customization
To personalize this portfolio further:

Update the text in index.html to detail your experience and expertise.

Swap the placeholder href attributes in the project cards with your actual GitHub repository URLs.

Connect the contact section to your preferred email routing service.
